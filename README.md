# MC1 Practice Mirror • Economics (RU / EN)

Тренажёр РК1, визуально и функционально воспроизводящий публичную страницу преподавателя **Principles of Economics — Midterm Control 1**. Создан для самостоятельной подготовки студентов Software Engineering.

## Запуск

- **После включения GitHub Pages:** https://amirmurat.github.io/economics-rk1-trainer/
- **Исходная страница тренажёра:** [index.html](./index.html).
- Для запуска из папки откройте `index.html` в браузере, подключённом к интернету (Tailwind, Chart.js и иконки загружаются с CDN).

## Что совпадает с оригинальным MC1

- Исходная структура и тёмное оформление страницы преподавателя: шапка, панель варианта, четыре вкладки, карточки заданий и калькулятор.
- **Часть 1:** 4 вопроса из полного банка по микроэкономике и издержкам.
- **Часть 2:** 5 вопросов из банка по рынкам и 1 вопрос с графиком.
- **Часть 3:** 4 расчётных задания, интерактивная таблица издержек на 10 единиц выпуска, графики.
- **Часть 4:** один из 3 экономических кейсов с ползунками, интерактивными диаграммами и письменным обоснованием.
- Первоначальные опубликованные формулировки на русском и английском, алгоритм распределения и числовые параметры **19 тренировочных вариантов**, графические сценарии и расчётные симуляции.
- Двуязычная навигация и адаптивная версия сайта.

## Что изменено именно для подготовки

- Вместо выбора фамилий студентов используется **выбор номера варианта 1–19** и кнопка случайного варианта.
- Добавлены **«Все 27 вопросов»** с возможностью раскрывать правильный ответ, локальная проверка тестов и расчётов, сброс текущего варианта.
- Ответы сохраняются только в `localStorage` браузера. Можно переключаться между вариантами, возвращаться к незавершённым заданиям.
- Экзаменационные ограничения (блокировка за переключение вкладок, запрет копирования), преподавательские пароли, реальные списки студентов, модуль преподавательского оценивания, формирование официального токена, передача результатов в Google Sheets **исключены**.
- Письменная часть не получает автоматическую итоговую оценку преподавателя: отображается объём текста, обратная связь по интерактивной части; содержание эссе оценивается самостоятельно.
- Тренажёр **не подключается к преподавательскому журналу и не может засчитывать РК1**.

## Включить GitHub Pages

1. Откройте [Settings → Pages](https://github.com/amirmurat/economics-rk1-trainer/settings/pages).
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, нажмите **Save**.
4. Дождитесь публикации сайта по адресу https://amirmurat.github.io/economics-rk1-trainer/.

Пользователь сообщает, что преподаватель разрешил студентам Software Engineering копировать сайт для подготовки. Это разрешение **не подтверждалось отдельно самим преподавателем**; ссылка на автора и источник сохранена. Не распространяйте учебный тренажёр как официальный экзамен или официальный сервис AlmaU.

**Это не твой обязательный тест Economics-se**, а тренировочная версия MC1 другого курса (*Principles of Economics / International Business*). Совпадение заданий с контрольной для SE не гарантировано. Не используйте сайт для подмены результатов официальной аттестации.

# ECON / RK1 Study Lab

Независимый двуязычный (RU/EN) сайт-тренажёр по микроэкономике для подготовки к первому рубежному контролю.

## Открыть сайт

После включения GitHub Pages: **https://amirmurat.github.io/economics-rk1-trainer/**

Если GitHub Pages ещё не включён, сайт доступен как исходный файл [index.html](./index.html): скачайте файл и откройте в браузере.

## Возможности

- 27 самостоятельно переформулированных вопросов по подтверждённым темам РК1, тренировка 10 случайных вопросов, полный банк и работа над ошибками.
- 4 графических сценария спроса и предложения.
- 4 расчётных раздела: рыночное равновесие и выручка, средние издержки, предельные издержки и таблица издержек на 10 единиц.
- 3 экономических кейса: совершенная конкуренция, монополистическая конкуренция, монополия.
- Интерфейс на русском и английском.
- Пояснения после тренировочных ответов, локальное сохранение прогресса в браузере.
- Адаптивный дизайн для компьютера и телефона.

**Без регистрации, серверной части и внешних библиотек.** Сайт состоит из одного автономного `index.html`; исходные стили, вопросы и логика встроены в него. Работает без интернета после скачивания.

## Включить GitHub Pages

1. Откройте [Settings → Pages](https://github.com/amirmurat/economics-rk1-trainer/settings/pages).
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, каталог **/(root)**, затем **Save**.
4. Дождитесь успешной публикации и откройте https://amirmurat.github.io/economics-rk1-trainer/.

Сайт размещён в корне репозитория специально для GitHub Pages.

## Источники и ограничения

Темы и виды заданий были сверены 12 октября 2026 года с публичными материалами преподавателя:
- [Principles of Economics — MC1](https://github.com/ogaydv-prog/principles-economics/tree/main/MC1)
- [Economics-se](https://github.com/ogaydv-prog/Economics-se)

Это **не официальный экзамен** AlmaU, не экзаменационный интерфейс и не гарантия совпадения вопросов с текущей рубежкой группы Software Engineering. Тренировочные формулировки, варианты ответов, визуализации и объяснения написаны отдельно. Числовые тренировочные задачи не являются назначенными преподавателем индивидуальными вариантами.

Исходный репозиторий преподавателя не содержит явно указанной лицензии на копирование. В этот сайт **не переносились** его JavaScript-код, персональные данные студентов, механизм аутентификации преподавателя, внешняя система оценивания или реальные ключи действующего экзамена. Не используйте тренажёр для обхода правил проведения официального РК1.

## Данные и приватность

Прогресс хранится только локально в браузере (localStorage). Ответы не отправляются на сервер. Для сброса прогресса используйте кнопку в разделе «Формулы».

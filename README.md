# MC1 Practice Lab — Economics / Software Engineering (AlmaU)

Самостоятельный учебный тренажёр, максимально близкий к текущему публичному интерфейсу РК1 по экономике для **Software Engineering**. Это **не официальный экзамен**: никакие ответы, оценки или личные данные не отправляются преподавателю.

**Открыть тренажёр:** https://amirmurat.github.io/economics-rk1-trainer/

## Актуальный источник

Оригинал преподавателя: https://github.com/ogaydv-prog/Economics-se/tree/main/MC1

Файлы `questions_p1_p2.js`, `tasks_p3.js`, `case_p4.js` скопированы из репозитория преподавателя для **Software Engineering** на 13 октября 2026 года. Они содержат исходные банки вопросов, русские и английские варианты текста, задания, числовые генераторы и кейсы. Если преподаватель обновит свой репозиторий, наш сайт нужно будет синхронизировать повторно.

## Как готовиться

1. На странице выберите ФИО в списке, **как в оригинальном экзамене**, или выберите номер варианта в тренировочном меню.
2. Используйте переключатель **RU / EN** справа в шапке (по умолчанию русский).
3. Пройдите четыре части: 4 тестовых вопроса, 5 тестовых вопросов и 1 график, 3 расчётные задачи и таблицу издержек, 1 кейс.
4. На вкладке **«Проверка ответов»** самостоятельно проверьте тестовые и числовые ответы. Полный банк из 27 вопросов доступен по кнопке.
5. Текст кейса необходимо набирать вручную, как на сайте преподавателя; минимальная длина — 60 слов.

## Распределение вариантов

**9 персонализированных вариантов**. Оригинальный алгоритм преподавателя сохранён: для частей 1–3 выполняется дополнительный сдвиг индекса студента, а для кейса выбранный тип определяется отдельной формулой.

По опубликованному списку **вариант №6** получает **кейс №3 — облачная инфраструктура (чистая монополия)**. Остальные студенты могут выбрать свой номер или ФИО; сайт не привязывает ответы к реальной аттестации.

## Принципы тренажёра

- Внешний вид, формулировки, варианты ответов, графики, ползунки и генераторы заданий воспроизводят опубликованные файлы Software Engineering.
- Переключение языка и вкладок; калькулятор.
- Локальное сохранение ответов в `localStorage` браузера; данные разделены по вариантам.
- Разбор правильных ответов и расчётных задач, включая подробную проверку клеток таблицы издержек.
- Экзаменационная блокировка вставки эссе сохранена для тренировки ручного ввода.
- **Нет** преподавательской панели, официальных токенов и Google Sheet/экзаменационной отправки: `grading_ai_engine.js` **не загружается**.

### Как формируется оценка в опубликованном официальном коде (на момент копирования)

| Часть | Баллы |
|---|---:|
| Теория и графики | 30 |
| Расчётные задачи | 25 |
| Кейс: положение ползунка | 10 |
| Кейс: обоснование от 60 слов | 35 |
| **Всего** | **100** |

В `grading_ai_engine.js` опубликованная автоматическая проверка длины текста присваивает 35 баллов после достижения 60 слов, но на стороне преподавателя предусмотрен отдельный эвристический ИИ-аудит. Формальное автоматическое начисление **не гарантирует** окончательную оценку эссе преподавателем. В учебном тренажёре эссе **не оценивается семантически** — его нужно проверять на правильность экономического объяснения.
